# Development Roadmap 🗺️

Pelan pembangunan ini dibahagikan kepada 3 fasa utama: MVP, v1 (Production), dan v2 (Expansion).

## Minimum Viable Product (MVP) - 4 Minggu
- [ ] Setup Repository & Folder Structure
- [ ] Authentication (Login & JWT)
- [ ] Dashboard UI Base
- [ ] Home Editor (Ubah kandungan muka depan)
- [ ] About Editor (Ubah info syarikat)
- [ ] Services CRUD
- [ ] Contact Form (Terima Mesej)
- [ ] Settings Asas

## Versi 1.0 (Production Release) - 4 Minggu
- [ ] Gallery CRUD (Cloudinary Integration)
- [ ] Team Member CRUD
- [ ] Blog / Artikel CRUD
- [ ] Testimonials & FAQ CRUD
- [ ] Integrasi penuh API dengan Public Website
- [ ] Security Hardening (Helmet, Rate Limit)
- [ ] Deployment (Vercel, Railway, MongoDB Atlas)

## Versi 2.0 (Future Expansion)
- [ ] Multi-tenant SaaS (Banyak syarikat dalam satu sistem)
- [ ] Multi-language (Sokongan pelbagai bahasa)
- [ ] Theme System (Tukar warna/tema website secara dinamik)
- [ ] Analytics Dashboard (Integrasi Google Analytics)
- [ ] Sistem Booking
- [ ] Modul E-commerce Asas
- [ ] Role-based permissions (Admin, Editor, Viewer)
- [ ] Audit logs
