# Company CMS 🚀

Company CMS adalah sistem pengurusan kandungan (Content Management System) yang dibina khas untuk perniagaan kecil, freelancer, dan agensi. Ia membolehkan pengguna menguruskan kandungan laman web tanpa perlu menyentuh kod.

## 🛠 Tech Stack
- **Frontend:** React, Tailwind CSS, TanStack Query
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Media Storage:** Cloudinary

## 🚀 Cara Menjalankan Projek (Local Development)

### 1. Clone Repository
```bash
git clone <repo-url>
cd company-cms
```

### 2. Setup Backend
```bash
cd server
npm install
npm run dev
```
*(Pastikan anda set `.env` untuk backend - rujuk `docs/API.md`)*

### 3. Setup Frontend
```bash
cd client
npm install
npm run dev
```
